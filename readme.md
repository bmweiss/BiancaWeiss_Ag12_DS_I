# 🌐 Meus Sites Favoritos

Página web simples que reúne os meus sites favoritos, exibindo uma imagem e o link de acesso para cada um deles.

## 📋 Sobre o Projeto

Este projeto foi desenvolvido em **HTML5** com o objetivo de praticar a estrutura básica de uma página web, incluindo:

- Títulos e cabeçalhos (`<h1>`, `<h3>`)
- Inserção de imagens (`<img>`)
- Links externos (`<a>`)
